TikZ Editor for Windows (x64), portable edition

Extract this ZIP into a writable local folder and run tikz-editor.exe.
The executable automatically creates tikz-editor-data beside itself. Keep that
folder with the executable when moving the app: it holds settings, recent files,
workspaces, recovery data, browser storage, logs and caches. No marker file is
needed. This edition uses its own profile, separate from the installed edition.

Updates: close TikZ Editor, extract the new portable ZIP over the program files,
and KEEP your tikz-editor-data folder. Update notifications offer a ZIP download;
this edition never runs an installer to update itself.

Microsoft Edge WebView2 Runtime must already be installed. It is present on most
Windows 10 and Windows 11 PCs. If missing, download the Evergreen Runtime from:
https://developer.microsoft.com/microsoft-edge/webview2/

Optional external tools such as TeX and Codex must be available on the computer.
Ordinary temporary files may use the Windows temporary folder. This edition does
not register file associations or install Start menu shortcuts.
